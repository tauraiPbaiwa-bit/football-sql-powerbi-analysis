# Football Data Analysis (SQL + Power BI)

## Project Overview
This project analyzes football match data using SQL for data processing and Power BI for visualization. The goal is to transform raw match data into meaningful insights about team performance and match outcomes.

---

## Tools & Technologies
- MySQL Workbench (Data Cleaning & Transformation)
- Power BI (Data Visualization)
- GitHub (Version Control)

---

## Data Processing (SQL)
- Converted date formats for proper analysis
- Created new features:
  - Goal Difference
  - Home Points
  - Away Points
- Applied football rules to calculate match outcomes
- Generated league table using SQL queries

---

## Key Insights
- Team rankings based on total points
- Goal scoring and defensive performance
- Home vs Away win distribution
- Overall match statistics

---

## Dashboard Features (Power BI)
- KPI Cards (Total Matches, Goals, Avg Goals, Win %)
- League Table with Rankings
- Goals Scored vs Conceded
- Match Outcome Distribution
- Interactive filters (Team, Date)
